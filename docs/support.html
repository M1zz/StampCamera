자주 묻는 질문

우표가 움직이지 않아요

  1. 카메라 좌측 상단 모습 버튼이 ◉ 라이브 우표 또는 ✨ 라이브 스티커인지 확인하세요. ▢ 우표 / ✂️ 스티커(정지 모습)로 찍으면 정지 상태로 보입니다(움직임은 보관돼요).
  2. 모음 화면 ⚙️ 설정에서 움직임 자동 재생이 켜져 있는지 확인하세요.
  3. 이미 찍은 우표는 상세 페이지의 모습 섹션에서 언제든 라이브로 바꿀 수 있어요.

메시지 앱에서 스티커가 안 보여요

메시지 앱 하단 앱 서랍에서 컬렉션을 활성화해주세요 (서랍 끝 ⋯ 더보기 → 편집). 꾹에서 우표를 한 장 이상 모은 뒤에 나타납니다.

진짜 스티커로 인쇄하고 싶어요

모음 화면 🖨 버튼의 인쇄 가이드를 따라가세요. 컬렉션 단위로 300dpi 인쇄용 PDF(우표 모양 칼선 포함)를 만들 수 있고, 집 프린터의 스티커 용지나 인쇄소에 바로 쓸 수 있습니다.

상태바에 초록불이 떠요

iOS의 카메라 사용 표시등입니다. 카메라 화면이 떠 있는 동안만 켜지며, 모음 화면을 여는 동안에는 카메라를 멈춰 불이 꺼집니다.

우표를 삭제하면 어떻게 되나요

우표·원본 사진·움직임 데이터가 기기에서 영구 삭제되고, 메시지 스티커 서랍에서도 사라집니다. 복구는 불가능하니 신중히!
