2. 권한 사용

  • 카메라 — 우표를 찍는 핵심 기능에 필요합니다. 카메라 화면이 떠 있는 동안에만 사용하며, iOS의 초록 표시등으로 항상 확인할 수 있습니다.
  • 위치 (선택) — 허용하면 우표에 장소 이름이 기록됩니다. 거부해도 모든 기능을 쓸 수 있습니다.

3. iMessage 스티커 (App Group)

모은 우표는 iMessage 익스텐션("컬렉션")이 읽을 수 있도록 기기 내 App Group 공유 폴더에 복사됩니다. 이 역시 기기를 벗어나지 않습니다. 사용자가 메시지로 스티커를 보내는 행위는 Apple iMessage를 통해 이루어지며, 해당 전송에는 Apple의 약관이 적용됩니다.

4. 공유·내보내기

이미지 공유, 인쇄용 PDF, 우표 PNG 내보내기는 사용자가 직접 실행할 때만 이루어지며, 공유 대상은 사용자가 시스템 공유 시트에서 선택합니다.

5. 데이터 삭제

  • 우표를 삭제하면 우표·원본 사진·움직임 데이터·스티커 사본이 기기에서 즉시, 영구적으로 삭제됩니다.
  • 앱을 삭제하면 모든 데이터가 함께 삭제됩니다. (외부 백업은 사용자의 iCloud/기기 백업 설정을 따릅니다.)
