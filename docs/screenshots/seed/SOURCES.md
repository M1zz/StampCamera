# 스크린샷 시드 사진 — 출처

스토어 스크린샷용 예시 사진. 모두 위키미디어 공용의 **CC0 / 퍼블릭 도메인** 사진이다(상업적 이용 가능, 저작자 표시 불필요).
파일 이름 앞 `a-`·`b-` 는 담을 수집함(`StampCamera/ScreenshotScene.swift`), `backdrop.jpg` 는 카메라 창에 비출 사진이다.
`cut/` 은 `tools/lift_subjects.swift` 가 맥의 Vision 으로 오려 낸 결과(시뮬레이터는 피사체 분리를 못 한다).
`crop/` 은 그 입력으로 앱이 내보내는 중간 파일이라 커밋하지 않는다.
